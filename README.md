# 150g Combat Robot

This is a 150g combat robot that I made that uses the gyroscopic forces of its weapon to move. This is a cool robot because instead of using wheels to move around, it uses bristles and an unbalanced weapon to create vibrations to get controlled movement,
kinda like a hex bug would. I made this because I have multiple combat robots, but I don't have a single good fairyweight bot, so for my first good fairy, I decided to make something that could be super powerful. This robot should be one of the hardest-hitting fairies if it works, because just the weapons alone weigh 2/3 of a normal fairy. For this bot, the wiring is super simple. The diagram I made is really bad, but this is how it goes. The positive goes to one side of the power switch, and the other side of the power switch goes to the ESC and receiver. The ground also goes to the receiver and esc. The three phase wires from the motor go to any of the three pads on the ESC. The signal wire from the ESC goes to channel 3 on the receiver.
